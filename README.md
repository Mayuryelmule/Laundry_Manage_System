# 🧺 Mini Laundry Order Management System (AI-First)

## 📌 Overview

This is a simple Laundry Order Management System built using **React (Vite)**.
It helps a dry cleaning store manage orders, track their status, and monitor revenue.

The project was developed using an **AI-first approach**, leveraging tools like ChatGPT to speed up development and problem-solving.

---

## 🚀 Features

### ✅ Create Order

* Customer Name
* Phone Number
* Garment Type (Shirt, Pants, Saree)
* Quantity
* Auto-calculated bill
* Unique Order ID

### ✅ Order Status Tracking

Orders move through:

* RECEIVED → PROCESSING → READY → DELIVERED
* One-click status update

### ✅ View & Search Orders

* View all orders
* Search by:

  * Name
  * Phone
  * Status

### ✅ Dashboard

* Total Orders
* Total Revenue

### ✅ Data Persistence

* Uses browser **localStorage**
* Data remains after refresh
